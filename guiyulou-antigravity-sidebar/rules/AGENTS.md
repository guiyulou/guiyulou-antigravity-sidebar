# guiyulou-antigravity-sidebar references

When a user message contains `[Ref n]` (n is a number), it refers to a passage the user selected in the right-hand panel labeled "侧边栏" and the comment they wrote; the chat line only carries the number and the first few words of the comment. The full records are in ~/.gemini/config/plugins/guiyulou-antigravity-sidebar/notes.md: each entry has the file path, the line or page, the element locator and source snippet (for HTML), the selected text and the full comment. Before handling a message with [Ref n], read that file, find the entry (see the next paragraph), then open the file and location it points to. An entry may instead say `Source: this conversation, message k`: then the quote is a passage from message k of the current conversation (said by the user or by you) and the comment is about that passage; nothing needs to be opened, just address that passage.

Numbering restarts at 1 with every message the user sends, so notes.md is grouped into rounds, newest first: `## Not sent yet` holds notes the panel has not yet seen go out, and each `## Round sent <time>` holds the notes that went out with one message. For a `[Ref n] <text>` line in the message you are handling, take the entry with that number whose `Label` is `<text>`, searching from the top of the file. Earlier rounds stay in the file so that older messages can still be looked up; they are not part of the current request.
