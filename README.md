## 七个亮点

- **文件树一目了然。** 项目原有的目录层级就在侧栏里。按文件夹找文稿，也可以直接搜文件名。
- **看到要改的地方，就地动笔。** Markdown、LaTeX 和代码都能直接在侧栏里编辑，点保存就写回原文件。
- **选中哪一格，就聊哪一格。** 选中周五的「30 分钟」，写下「把周五改为 100 分钟」，点「加入对话」。原文旁的 `1` 和聊天框里的 `[Ref 1]` 指向同一格。发送后输入框清空，点「清理」并确认即可清除批注记录。
- **一键全屏，展开整份文稿。** 遇到宽表或整页 PDF，点右上角的全屏按钮，把整个窗口的宽度用来阅读。
- **左边看成稿，右边改源稿。** 把 PDF 和 LaTeX 源稿分屏打开，再一起展开到全屏。排好的表格和对应的代码可以一行一行对照。
- **全屏时也能继续对话。** 点 `Chat` 调出输入框，再点一下展开聊天记录，最后再点一下收起。像视频里那样发一句「请你编辑」，PDF 和源稿都还在眼前。
- **刷新以后，接着看刚才那一行。** 重新编译再刷新 PDF，第二页的数字已经更新，阅读位置还留在周五这一行。

## 阅读和批注

- **打开文件。** 左侧目录树可以浏览工作区，搜索框按文件名查找。最多同时打开 8 个标签页。把标签页或目录树里的文件拖到显示区右半边，就能并排阅读。点工具栏的 `Refresh` 可以重新读取当前文件。
- **阅读或编辑。** PDF 支持缩放和文字批注。Markdown 可在 `Read`、`Live`、`Source` 三种视图之间切换。代码和纯文本可直接编辑，点击 `Save` 会写回原文件。
- **预览 HTML。** 点开 HTML 文件时，预览会立即运行网页自带的脚本，交互图表也能随页面加载。**只在面板中打开自己编写或确认可信的 HTML 文件。** 预览页面和插件面板共享访问权限。来源不明的 HTML 建议先用文本编辑器查看。
- **添加评论。** 在正文中选中文字，点 `Comment`，写下评论，再点 `Add to chat`。文中会出现编号，插件会尝试将类似 `[Ref 1] 请核对单位` 的文字填入对话框。你可以继续编辑，再自行发送。
- **管理批注。** 点正文中的编号可以修改或删除评论。顶栏的 `Notes` 列出本轮批注，可以从列表跳回原文。发送带引用的消息后，新一轮从 1 重新编号。`Clear all` 会清除本轮和过往各轮的全部批注。
- **在面板里查看对话。** 面板最大化后，第一次点 `Chat` 会显示原有对话输入框，再点一次展开聊天记录，第三次点击收起。还可以在展开的聊天记录中选中文字写评论。
